# Meine Abos

Übersicht aller Abos mit Resttagen bis zur nächsten Verlängerung. Erinnerungen 7 Tage und 1 Tag vorher über den Kalender (Knopf in der App erzeugt eine .ics-Datei).
Installieren: Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
Die Abos liegen nur auf dem Gerät (kein persönlicher Inhalt im Code); übertragen/sichern per Code.
